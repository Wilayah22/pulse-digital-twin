# Pulse — التوأم الرقمي لتوزيع مياه الري

**Pulse** نظام ذكي لتوزيع مياه الري بين أحواض النخيل التقليدية في واحة الأحساء. هذه اللوحة توأم رقمي تفاعلي يحاكي ثلاثة أحواض وخزاناً مشتركاً لمدة 7 أيام، ويقارن قرارات Pulse بالري التقليدي تحت نفس الطقس ونفس كمية المياه.

> Pulse لا يقرر متى نروي فحسب، بل كيف نوزّع كل قطرة متاحة بذكاء بين الأحواض.

## التشغيل محلياً

```bash
npm install
npm run dev     # http://localhost:3000
npm test        # اختبارات محرك المحاكاة
npm run build   # موقع ثابت في مجلد out/
```

## النشر على Render

المستودع يحتوي على `render.yaml`، ويُنشر كموقع ثابت مجاني:

1. في https://render.com: **New → Blueprint**.
2. اربط حساب GitHub واختر هذا المستودع.
3. اضغط **Apply**. بعد البناء يظهر رابط عام بصيغة `https://pulse-digital-twin.onrender.com`.

كل `push` إلى الفرع الرئيسي يعيد النشر تلقائياً. لا توجد متغيرات بيئة أو مفاتيح مطلوبة.

## المنهجية العلمية (`src/pulse/engine/`)

محرك المحاكاة مستقل عن الواجهة، ومكتوب كدوال نقية قابلة للاختبار:

- **التبخر-النتح** `et0.ts`: معادلة بنمان-مونتيث FAO-56، و ETc = Kc × ET0. قيمة Kc الافتراضية 0.95 مؤقتة وتجريبية، ويمكن تعديلها من الواجهة.
- **الموازنة المائية** `waterBalance.ts`: موازنة يومية لمنطقة الجذور (FAO-56 المعادلة 85): الري، والمطر الفعّال، والتبخر-النتح، والتسرب العميق، ومعامل الإجهاد Ks.
- **الملوحة** `salinity.ts`: ملوحة مياه الري ECw منفصلة عن ملوحة التربة ECe، مع موازنة أملاح ومتطلب الغسيل (FAO-29). يُقارن بحد تحمّل النخيل لملوحة التربة، وليس بحد عام لملوحة المياه.
- **التوزيع** `allocation.ts`: أولوية حسب الاستنزاف والطلب والملوحة، ومقيدة بمخزون الخزان المشترك، مع تقنين حسب الاحتياج المتوقع. يؤجّل غسيل الأملاح إذا كان المطر المتوقع سيقوم به.
- **المقارنة** `simulate.ts`: Pulse مقابل ري تقليدي بحصص ثابتة تحت نفس الظروف.
- **التوصيات** `recommendations.ts`: كل توصية مستخرجة من النتائج المحسوبة.

بيانات الطقس من [Open-Meteo](https://open-meteo.com) لإحداثيات الأحساء (بما فيها `et0_fao_evapotranspiration`). عند تعذر الاتصال تعمل اللوحة على سيناريو تجريبي موسوم بوضوح.

## الصفحات

- `/`: تعريف بالمشروع في 5 خطوات: الترحيب، والتحدي، وكيف يعمل Pulse، وما داخل المحاكي، ثم نتائج محسوبة من محرك المحاكاة.
- `/simulator/`: المحاكي ولوحة التوأم الرقمي.

## الميزات للعرض

- **العرض التقديمي:** جولة تلقائية بملء الشاشة عبر ستة سيناريوهات، ونصوصها مأخوذة من نتائج المحاكاة.
- **عربي / English:** زر في أعلى الصفحة يحوّل الواجهة والتوصيات واتجاه الصفحة.
- **تقرير PDF:** يُنشئ تقرير A4 من نتائج السيناريو الحالي (الملخص، والظروف، والرسوم البيانية، والجداول، والتوصيات، والأثر، والمنهجية). يفتح نافذة الطباعة، فاختر «حفظ بتنسيق PDF».
- **الأثر على مستوى الواحة:** تقدير سنوي بافتراضات ظاهرة وقابلة للتعديل.

## البنية

- `src/pulse/engine/` محرك المحاكاة واختباراته
- `src/pulse/weather/` خدمة Open-Meteo
- `src/pulse/state/` الحالة المركزية والمحددات المشتركة
- `src/pulse/components/` الواجهة: التوأم الرقمي، والتحكم، والمؤشرات، والرسوم البيانية، والتوصيات

البيانات الأولية للأحواض (المساحة، والرطوبة، والملوحة، وخصائص التربة) قيم افتراضية للعرض في `src/pulse/engine/constants.ts`، وتُستبدل ببيانات ميدانية.
